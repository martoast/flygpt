# FlyGPT Lab

Research scaffold for testing whether externally learned sequence computation can be implemented by recurrent networks constrained to a Drosophila connectome.

## Core hypotheses
- H1: a real connectome-constrained recurrent network can learn non-trivial sequence prediction.
- H2: it differs from degree-matched rewired/random controls under matched training budgets.
- H3: a pretrained transformer teacher can be functionally distilled into the connectome network.

## Data
Download the official MaleCNS v1.0 aggregate connection table from Janelia and place it at:
`data/raw/connectome-weights-male-cns-v1.0-minconf-0.5.feather`

Optional annotations:
- `body-annotations-male-cns-v1.0-minconf-0.5.feather`
- `body-neurotransmitters-male-cns-v1.0.feather`

Official dataset page: https://male-cns.janelia.org/download/

## First run
```bash
pip install -r requirements.txt
python -m src.prepare_malecns --input data/raw/connectome-weights-male-cns-v1.0-minconf-0.5.feather
python -m src.train_sequence --graph data/processed/malecns_graph.npz --steps 2000
```

## Smoke test
`python run_smoke.py`

The smoke test uses synthetic sparse graphs only. It validates the training machinery; it is **not** evidence about the fly connectome.

## Interactive query milestone
After language training, `train_language` now writes a checkpoint automatically. Query it with:

```bash
python -m src.query_flygpt \
  --graph data/processed/malecns.npz \
  --checkpoint results/fly_real.pt \
  --prompt "Once upon a time" \
  --max-new 300
```

Or omit `--prompt` for a REPL. Generation is stateful: prompt bytes are first propagated through the graph, and every generated byte is fed back through the same recurrent connectome state. The decoder never bypasses the graph core.

**Success criterion:** a checkpoint trained on the real MaleCNS topology must generate non-trivial held-out language and beat matched controls under preregistered comparisons. A synthetic-graph demo validates software only; it is not evidence about the fly connectome.

## v0.3 causal query-path validation

Run:

```bash
python validate_query_path.py
```

Expected result (seed 123):

```text
intact:   Q:a? A: -> x
          Q:b? A: -> y
ablated:  both -> :
```

The model uses disjoint input/output neuron populations, so this edge-ablation is a causal check that prompt identity is transmitted through recurrent edges.
