# Queryable Brain Target

The project's concrete endpoint is an interactive system where a user enters text and receives generated text whose recurrent computation is constrained to the biological graph.

## Level 1 — Digital connectome substrate (current experimental target)
Input encoder -> MaleCNS-constrained recurrent state -> output decoder. All temporal/contextual computation must pass through the recurrent connectome state. This is testable now.

## Level 2 — Neuromorphic physical substrate
Map the same graph/state update onto event-driven neuromorphic hardware. This establishes that the learned connectome model can execute on a physical neural-style substrate rather than a conventional dense GPU abstraction.

## Level 3 — Living neural substrate
A living fly brain or engineered neural culture would require technologies unavailable today: high-bandwidth identification of corresponding neurons, precise bidirectional I/O, and especially massively parallel programming of effective synaptic state. A digital FlyGPT checkpoint can serve as a target specification, but current biotechnology cannot flash that checkpoint into millions of specified living synapses.

## Non-negotiable evidence rule
We will not describe Level 1 or Level 2 as a literal biological upload. The literal wetware claim becomes warranted only if the learned state itself is instantiated in living neural tissue and queried through biological activity.
